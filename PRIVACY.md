# Privacy Policy — ChatGPT Visual Exporter

**Effective date:** November 26, 2026

## Overview

ChatGPT Visual Exporter is an independently developed Chrome extension that enables users to export ChatGPT conversations, individual messages, and visual elements as PDF or standalone HTML documents.

## Data Access and Processing

The extension accesses conversation content, conversation titles, page formatting, images, and rendered visual elements when the user explicitly initiates an export.

Conversation content may contain personal or sensitive information supplied by the user. This information is processed solely for generating the requested export.

Export processing takes place locally within the user's browser. The extension does not operate a remote data collection service.

## Data Storage

Exported PDF and HTML files are saved to the user's device.

The extension stores the user's preferred export format locally within the browser. It does not maintain a separate database of conversation history.

Users are responsible for managing, sharing, and deleting their exported documents.

## Data Sharing

The extension does not sell user data, use conversation content for advertising, or transmit conversation content to developer-operated servers.

Externally referenced images and other resources may be retrieved by the browser during document rendering or when opening exported HTML files. Such requests are subject to the privacy practices of the corresponding resource providers.

## Browser Permissions

The extension requires the following Chrome permissions:

- **activeTab:** Provides temporary access to the active ChatGPT tab following user interaction.
- **scripting:** Enables the bundled export script to capture conversation content and formatting.
- **debugger:** Enables Chrome's native PDF generation functionality in a temporary browser tab. The debugger is not attached to the original ChatGPT conversation tab.
- **downloads:** Enables generated PDF documents to be saved to the user's device.

These permissions are used exclusively to support the extension's export functionality.

## Analytics and Tracking

The extension does not include advertising, analytics, telemetry, or behavioral tracking services.

## Limited Use Compliance

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

## Changes to This Policy

This privacy policy may be updated to reflect changes in the extension's functionality or applicable privacy requirements.

## Contact

Questions or concerns regarding this privacy policy may be directed to the developer through the contact information provided on the Chrome Web Store listing.

ChatGPT Visual Exporter is not affiliated with, endorsed by, or sponsored by OpenAI.
